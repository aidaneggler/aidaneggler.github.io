SPRUCE PORTFOLIO — HOSTING & EDITING

This folder is the complete website: ordinary HTML and CSS, with no install or server required for hosting. The two Unity games are hosted separately on GitHub Pages and linked from the Projects page.

BEFORE PUBLISHING
The name Aidan Eggler is already included throughout the site. Review the draft biography and project descriptions. Add your own contact/profile links if desired. The resume PDF has not been supplied, so its unavailable state is intentional.

HOST ON GITHUB PAGES
1. Create a public GitHub repository named YOURUSERNAME.github.io. Replace YOURUSERNAME with your actual username. If you already use that repository for another site, do not overwrite it without backing it up.
2. Upload all files and folders in this ZIP to the repository root. index.html must be at the top level. Keep assets/, projects/, and resume/ intact. Do not upload the ZIP itself as the website.
3. Open the repository's Settings, then Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose main and /(root), then Save.
6. Open the URL shown by GitHub. Allow time for the deployment to finish.

An empty .nojekyll file is included. If your computer hides it during upload, create an empty file named .nojekyll directly in the GitHub repository.

The portfolio URL will be https://YOURUSERNAME.github.io/ . Public-repository hosting is available on GitHub Free. A custom domain is optional; you can add one later in Pages settings.

FILES
index.html              Home page and biography
projects/index.html     Project descriptions and links to the playable games
resume/index.html       Resume page and future PDF link
assets/portfolio.css    All styles, colors, spacing, and mobile layouts
favicon.svg             Small spruce tree browser icon
404.html                Page-not-found screen
.nojekyll               Disables Jekyll processing

This export can be edited directly. To inspect it locally with directory links working, open a terminal in this folder and run:
python3 -m http.server 8000
Then open http://localhost:8000 . Do not expect directory navigation to work from a file:// URL.

ADD YOUR RESUME LATER
Place resume.pdf in the root of this folder. Replace the resume-pending section in resume/index.html with a PDF link, for example:
<a class="button" href="../resume.pdf" target="_blank" rel="noopener noreferrer">View resume PDF</a>

UNITY GAME LINKS

To change a game's address later, update the href on its Play in browser link in projects/index.html.

No Unity game files are included in the portfolio itself. Updates to a game build belong in that game's repository.

EDITING THROUGH THE SOURCE PROJECT
The source project keeps all personal text and links in lib/portfolio.ts. Set name, email, github, linkedin, resumeUrl, and each project's playUrl/sourceUrl there. Rebuild to generate this static folder. The generated HTML can also be maintained independently without the source project.
